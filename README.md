## Features

### Authentication
- User Login
- JWT Authentication
- Protected Routes
- Password Hashing

### Lead Management
- Create Lead
- View Leads
- Delete Lead
- Update Lead

### Dashboard Features
- Search Leads
- Filter by Status
- Filter by Source
- Sorting
- Pagination

### Deployment
- Frontend deployed on Vercel
- Backend deployed on Render
- MongoDB Atlas Database
